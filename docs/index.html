Resource Manager for grandMA

grandMA3 / grandMA2 のファイルに素早くアクセスするための Mac / Windows アプリ。ローカル onPC・USBメモリを横断して Shows / Macros / Presets などに一発でジャンプし、ドラッグ&ドロップでインポート/エクスポートできます。

macOS 用をダウンロード Windows 用をダウンロード

インストーラ不要・無料。未署名アプリのため初回起動時に警告が出ます — 開き方はREADME参照

主な機能

  • USBメモリを挿すだけで自動検出、ワンクリックでSourceとして追加
  • ローカル onPC・USBメモリを横断してファイル管理
  • Shows / Macros / Sequences / Presets などのフォルダ構成をワンクリックでナビゲート
  • grandMA3 / grandMA2 両対応
  • ドラッグ&ドロップでのインポート/エクスポート
  • ファイルのリネーム・削除(確認ダイアログ、ゴミ箱送り)
  • クイックオープン検索(全Source横断)
  • フィクスチャライブラリのメーカー名でのフィルタ
